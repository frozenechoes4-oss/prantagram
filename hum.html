One-time setup

  1. Make a free Supabase project at supabase.com (Start your project → New project). Choose any name and a database password, then wait about a minute.
  2. Create the database. In Supabase open SQL Editor → New query, paste the code below, press Run.
  3. Turn off email confirmation. Authentication → Sign In / Providers → Email → switch off Confirm email → Save.
  4. Connect this page. Supabase → Project Settings → API: copy the Project URL and the Publishable key (or anon key). Paste them into the two lines at the very top of this file (CHAT_CONFIG), save, and upload it to GitHub.

Never paste the service_role / secret key into this file.
